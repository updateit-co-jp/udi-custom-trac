udi-custom-trac

update it の Trac フォーク版です。ここではダウンロード方法とインストール・アップグレードの手順を案内します。

ダウンロード

wheel ファイル（.whl）は GitHub Releases から取得してください。 日付付き開発版は「Pre-release」として公開されます。

GitHub Releases を開く

クイックインストール

仮想環境を作り、ダウンロードした wheel を指定してインストールします。ファイル名は実際のものに置き換えてください。

python -m venv /path/to/venv
/path/to/venv/bin/python -m pip install /path/to/trac-X.Y.Z-py3-none-any.whl

詳しい手順は インストール手順 を、既存環境の更新は アップグレード手順 を参照してください。
